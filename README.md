# GIROK COFFEE — Website prototype

## Included
- `index.html` — single-page homepage
- `styles.css` — responsive black editorial design
- `script.js` — mobile navigation and footer year
- `assets/girok-logo-transparent.png` — transparent white logo extracted from supplied black version
- `assets/girok-logo.png` — original supplied logo image
- `assets/girok-interior.webp` — web-optimized supplied interior photo

## Before publishing
1. Confirm the official address spelling and map link.
2. Add the exact weekly opening hours and holidays.
3. Replace the temporary menu note with confirmed menu items and prices.
4. Review the current logo image against light backgrounds if you later add any.
5. Test on mobile and desktop.

## GitHub Pages
Upload the contents of this folder to the root of a GitHub repository, then go to Settings → Pages and select deployment from the `main` branch / root folder.
